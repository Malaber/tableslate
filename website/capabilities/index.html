Capabilities

A native score keeper, shaped around the game.

TableSlate combines fast input with a safe definition engine, reliable local storage, and layouts designed for both iPhone and iPad.

Fast entry

One-tap quick values for short ranges, a dedicated numeric keypad, automatic advancement, large targets, haptics, and undo.

Game recovery

Every meaningful mutation auto-saves. Multiple active sessions can be resumed after termination or restart.

Reusable players

Create people once, then select them for any future game. Completed history preserves names even if the player library changes.

Declarative engine

Versioned JSON definitions describe inputs, progression, scoring expressions, validation, and results without executable code.

Safe import

Local definitions are bounded by file size, schema, identifier, field, expression-depth, and expression-complexity checks.

Inclusive layouts

Dynamic Type, VoiceOver labels, non-color status cues, Reduce Motion support, and responsive iPad composition are built in.
