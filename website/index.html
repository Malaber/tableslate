Built for the table

Scores survive the interruptions.

Every meaningful change is saved immediately. Resume after a call, an accidental close, or a device restart without rebuilding the score sheet.

  • Large one-handed controls and a dedicated numeric keypad
  • Quick undo after any score change
  • Multiple unfinished games can wait safely
  • Purposeful iPad layouts in portrait and landscape
  • System, light, and dark appearance
  • VoiceOver and Dynamic Type support

OPEN DEFINITIONS

Rules, not executable code

Games are versioned declarative JSON. Safe, bounded expressions calculate scores without scripts, network access, or hidden game-specific logic.

Community-ready

A score sheet library that can grow.

Import a local .tableslate-game.json file. Each completed game keeps the exact definition version it used, so history never changes under your feet.
